# 1.13 可操作页面与能力合同

本文件定义要生成的产品行为；新增媒体、群聊、审批、子代理、兼容、通用MCP、编排与多节点页面目前未实现。当前页面继续遵守 `WORKFLOWS.md`、`DESIGN.md` 及递归 `service` 包的完整 `OPENAPI.md`；未来对象只经该包 `EXTENSION_API.md` 的版本协商开放，不能对 v1 猜路径。当前能力查询、支持状态、权限状态、可用状态必须来自服务端；本文件不是另一份权限表。

## U01 请求、状态和输入的公共规则

每个读请求捕获 `(origin, authenticated_user_id, workspace_id, resource_id, revision, ui_epoch)`；响应只有全部相同才能更新页面。身份变化递增 epoch，停止流/读取，清除旧用户内存、私有查询缓存和临时秘密；取消浏览器请求不能撤回已提交服务端事务。每个写意图另保存服务返回的 operation/run/delivery ID；失联后先只读核对，用户继续相同意图才复用原幂等键。改变正文、目标、审批参数或有效配置版本属于新意图，不能偷换旧键。

页面状态是业务状态投影，禁止只用 `loading=false` 当成功：

| 状态 | 页面必须提供的内容 | 恢复动作和副作用 |
| --- | --- | --- |
| 尚未配置/空列表 | 准确空原因、权限允许的创建入口、页内教程；筛选为空与不存在资源分开 | 调整筛选或配置；不暗中创建演示数据 |
| 加载/排队/处理中 | 已确认事实、进度来源、可取消范围；没有进度值时不造百分比 | 停止等待或业务取消单列；已提交写入仍核对真实终态 |
| 不支持 | 缺少的服务/协议/插件能力和合同目标 | 展示只读说明；不能启用假按钮，也不删对应需求 |
| 未授权 | 所需权限范围；不显示别人资源、存在性或秘密 | 申请权限说明；401重新登录，403清访问缓存，404不泄露目标 |
| 已支持但不可用 | 缺运行时、连接、插件就绪、恢复隔离等实际原因 | 修复配置、只读健康核对、显式重新启用；不得静默放宽权限 |
| 校验失败/配置冲突 | 字段错误与当前服务版本；保留不含秘密的草稿和差异 | 修正字段、重新读取并合并；禁止覆盖别人新版本 |
| 部分完成 | 每个子项/目标独立的生成、发送、保存和结算状态 | 只处理明确未开始且仍获准的子项；unknown 不在自动重试集合 |
| 已取消/已中断/结果未知 | 哪些步骤已提交、已观察到何种外部效果、哪些仍不可确认 | 只读回执/下游核对；取消不写成“什么也没发生” |
| 成功/恢复后 | 持久对象ID、版本、来源/时间及授权读回结果 | 刷新或重开后仍一致；成功提示不替代真实下游结果 |

数字按 API 单位显示，费用用整数微美元转换；未知 usage/price 显示未知，不当零。超长字符串按 UTF-8 字节校验，不按 JavaScript 字符数误算。敏感输入不写浏览器持久草稿、URL、错误遥测或教程示例。每页可导出的只包括当前获准数据；导出重新核权，按钮可见不构成权限。

## U02 有限选项与开放字段

| 控件 | 可选集合与实际来源 | 自定义、无效值与失效处理 |
| --- | --- | --- |
| 界面语言/主题/导航 | `zh/en`；`light/dark`；侧栏/顶栏；来自当前产品设置 | 不自动新增locale或把双语并排；移动布局由实际视口收纳，保留用户导航偏好 |
| 工作区/成员/会话/模型/代理/路由 | 当前 API 分页中已授权对象，显示名称与可区分的ID尾部 | 支持搜索/继续加载；不得让用户猜ID；旧选中项失权时撤销，不能改选第一个继续执行 |
| 工作区角色 | 当前 `Role` 的 `viewer/member/operator/admin/owner`；仅显示调用者可授予项 | 不允许自造角色字符串；最后所有者等服务端拒绝定位到此操作 |
| 模型提供方/模型ID | 已安装 `model` 包；支持 `model.list` 的实际返回，最多500净化、去重项目 | ID为开放输入；空/失败/截断均保留手填；不得把曾发现ID当永远可调用 |
| 渠道/传输 | 当前仅已接入Webhook；未来来自支持、授权、可用三态的真实平台实例 | 未装渠道显示缺口；地址/自定义平台ID是明确开放字段，不能自由覆盖已有路由的安全目标 |
| 计划类型/频率 | `once/interval/cron`；每日、每小时、自定义是界面预设 | 预设生成现有六/七段cron，秒段固定整数；interval按现有60至31536000秒范围；仍由核心校验 |
| 时区 | 浏览器实际 `Intl.supportedValuesOf('timeZone')`（可用时），标来源；最终由核心preview验证 | 可输入IANA ID；浏览器不支持枚举则提供手填与帮助，不用硬编码短列表冒充全部时区；不得把设备时区静默覆盖计划时区 |
| 错过/DST策略 | 当前仅 `skip`、`first_occurrence_skip_gaps`，来自preview实际返回 | 不展示当前不可保存的catch-up选项；暂停下候选时刻明确标“不会派发” |
| 可见范围/记忆状态 | 当前允许的private/workspace；记忆enabled/archived/pinned独立字段 | 共享并非公开链接；既有资源可见范围不可经普通编辑变更时禁用该控件 |
| MCP/技能/媒体/编排 | 仅列服务协商成功的协议、传输、解析器、mime、沙箱和节点类型 | 缺后端就绪不宣称可运行；使用“未实现/运行时缺失”区别原因，保留目标说明 |

可编辑建议框采用有标签的原生控件或可测试的 combobox 语义：上下键浏览、Enter选择、Escape关闭、Tab按自然顺序移动。选项加载期间不把键盘焦点跳走；选中建议不等于保存或发送。只有确认步骤中的显式动作才提交。参考 [W3C Combobox Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)，本合同未声称已通过无障碍认证。

## U03 RFB三个修复必须保留

RFB-001：本机提示词原子记录含基线版本/摘要、草稿、最多20条版本及其时间，键绑定准确实例来源与已认证稳定用户ID。存储提交前再次核对 epoch，读失败与写失败分别说明；不靠逐项散写留下半个版本。登录/退出、改密、Passkey成功、模拟OAuth成功返回的跨标签页通知只传事件/身份变化信号，不能广播正文或令牌。旧匿名全局键保留原样，不读取展示、不自动认领、不导出；另一个账户不能凭“我在同一浏览器”认领。清缓存不得删除同账号正常版本。存储不可用时允许内存编辑及用户明确下载当前稿，刷新会丢失须直说。

RFB-002：选择Asia/Tokyo每日09:00，用核心只读preview返回UTC时刻，再显示计划与设备时区；设备Asia/Taipei显示08:00。实际 tzdb 是执行依据，测试记录浏览器/核心tzdb版本，不能假设枚举相同即规则相同。编辑字段、换身份、换工作区或关闭窗口使旧预览无效；保存使用同一白名单和验证规则。preview不得有模型请求、任务写入或投递。跨DST测试使用冻结日期和规则版本，不用“今天下一次”作不稳定断言。参考 [IANA Time Zone Database](https://www.iana.org/time-zones)。

RFB-003：网络异常保留原始意图正文和用户后来输入的新稿，主提示只用当前语言，技术详情默认收起。明确“暂时无法确认是否已收到”，提供只读运行/历史/回执核对。恢复网络不会自动发送；手动继续相同意图保持原键，新的发送重新确认。401/403进入认证/授权路径，不能伪装断网。只有确认对应 draft_revision 的接受结果才清其旧稿，迟到确认不能清空新稿。

## U05 页内教程与提示词版本交付

教程索引固定包含：同源启动与初始化；账户/工作区隔离；模型发现与真实测试的费用区别；只读插件；Rust/Python/TypeScript/C#各一个实际进程示例；当前协议与未来协商；独立Webhook MCP；备份恢复与unknown核对；插件安装/兼容/沙箱缺口；提示词本机版本升级规则。每篇含先决条件、实际命令或界面步骤、预期下游结果、常见失败与清理，以及当前支持版本。示例和命令由同版生成物提供，未生成/未运行的命令示例标目标，不伪作本轮回执。

教程离线可读，链接指向随包文档索引及权威来源；外链失败不妨碍阅读正文。四SDK链接必须各有独立入口，不用一个Python示例代替全部语言。两个项目自有技能作为普通文件随包交付；共享Recipkg开发技能留在仓库级固定上游子模块，不作为产品运行时依赖。

构建时嵌入当前根提示词1.13的UTF-8原文、版本和SHA-256；独立源码包附同内容快照。UI同时显示仓库基线与用户本机稿，不能自动覆盖已编辑稿；新基线差异可查看，合并后生成新本机版本。导出明确文件名/版本/来源且不含身份令牌。选择旧版本恢复只改当前用户草稿，不修改历史、不写Git。版本上限20按成功原子提交的时间/稳定序号淘汰最老项；失败写入不能先删旧版。

## U06 窄屏、键盘、动效和语言

320/390/768/1024/1440 CSS px × zh/en × light/dark × 侧栏/顶栏至少覆盖主任务；另测200%缩放、系统减少动作、实际读屏和触屏设备。320px无主流程横向滚动；二维数据表/节点图可局部滚动，但名称、状态与主要操作也须有线性列表方式。不能把320px截图当200%或读屏已通过。参考 [W3C Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)。

焦点顺序跟视觉任务顺序，弹窗焦点限制且Escape回原控件；禁用操作有文本原因。错误摘要链接到具体字段；选择框展开/收起有状态。流式内容按完整短句/终态通知读屏，不能每token打断。中文IME组合时Enter不提交；Shift+Enter换行。导航自动显隐依据真实scrollTop/方向/迟滞，聚焦、选区、菜单和程序恢复滚动期间不收走控件。

粒子只在欢迎/空态/教程等装饰位置，默认不传达运行健康或费用；屏幕外、页面隐藏、卸载时释放监听器/RAF/资源，减少动作使用静态原创图形；暂停后无后台动画循环。轻度原创干幽默仅用于无风险空态；认证、预算、未知投递和数据删除准确直说。中英文文案分开加载并完整测试，不能把内部键或另一语言说明作为正常显示。
