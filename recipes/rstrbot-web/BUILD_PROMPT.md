# TypeScript / React Web 工作台

实现可独立部署为静态资源的TypeScript前端，采用当前React路线；核心和SDK语言保持，辅助工具可选择。依赖 `service` 提供同源真实API与测试进程，归档内 `.deps/service/`；前端开发时需要它验证认证、权限、数据与副作用，生产浏览器无需装Rust/Node。依赖中的schema是表单和状态的事实来源。

读 [DESIGN.md](DESIGN.md) 与 [WORKFLOWS.md](WORKFLOWS.md)。所有当前源流程与上一轮未提交的视觉/教程改动都须保留。未来实现可重设内部组件，但不得用静态界面、假回执或固定样例替代真实业务。

## 导航和阅读

左侧栏/顶栏两种可切换布局持久保存偏好，当前工作区、页面和权限过滤一致。桌面顶栏按工作、知识与代理、连接、工作区管理、账号、开发者分组菜单组织；中等宽与手机采用抽屉。侧栏与会话列表各自可折叠，按钮有label/expanded。自动收起依据实际滚动位置与用户方向、阈值和迟滞，避免抖动；手动偏好与自动状态分开。输入聚焦、弹窗或菜单操作时保持控件可用，不抢滚动或丢失聊天锚点。

## 数据与表单

所有API请求按用户/工作区/会话键隔离，切换取消旧读请求并忽略迟到结果，已提交写入不因卸载伪报取消。401清认证缓存，403/404清对应访问缓存；重新登录换用户不可看到上一人私有数据或草稿。模型输出只作安全文本；坏历史逐条跳过、稳定ID去重，终态不能被迟到delta复活。

模型和渠道按身份/连接、凭据与限制、确认分步。模型来源由真实已安装model能力与service当前接受的provider约束共同决定；当前只支持openai/diagnostic，其他已安装声明不等于已集成。地址、真实模型ID和密钥保留自由输入与准确格式。用白名单构建请求，不回传只读状态/has_secret标志；同一完整目标保留秘密，变更需替换/清除。测试显式说明真实调用与费用可能未知。渠道当前只列Webhook，无无副作用测试接口就不显示假“测试成功”。

Webhook保存、授权、启用、发送不同状态。继续原POST使用同key仍可能首次发出请求，不能称为只读查询；新的发送必须先确认核对过目标结果。URL、费用、token、文本按服务UTF-8与整数约束；小数微美元转换避免二进制舍入。

## 教程与构建提示词

开发者教程嵌入启动、四SDK、只读插件起步、调试/协议验证和故障边界，相关链接指向随产品交付的权威文档与技能。配方根提供两个skills/入口，重建后映射到产品开发文档。

编辑构建提示词时区分仓库基线、浏览器草稿和最多20版本的本地历史；支持时间、差异、恢复及Markdown导出。浏览器保存不宣称写回Git。用户每次改进要求都更新项目重建基线并保留旧版本与可验收变化；当前源基线1.4由迁移根保存。

## 国际化与限制

中文和英文各自完整显示，主题深浅两套。UI不能逐句双语并排；SDK、模型ID和协议名字可保留专有拼写。日期输入用明确设备时区，cron选IANA时区；数字/时间在显示层本地化，API仍稳定。RTL、新locale、完整日期地区标签暂未指定，不能擅称覆盖。中文原创轻微干幽默，不淡化权限、费用和错误。
