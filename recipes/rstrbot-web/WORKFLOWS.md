# 页面、输入与状态

| 页面 | 主要输入/操作 | 必须显示的结果与边界 |
| --- | --- | --- |
| 初始化 | 终端证明、管理员、工作区，SQLite/PG测试/选用 | 测试与应用分开；类型改动未应用则阻止完成；已有实例不重置 |
| 登录/恢复 | 用户名或验证邮箱、密码；Google/Passkey；邮件重置 | 登录方法依据实例配置；通用重置答复不泄露账户存在；证明失败不误清仍有效会话 |
| 账号安全 | 邮箱验证/替换、密码、Google显式绑定、多Passkey添加/重命名/替换/删除 | 无需工作区；敏感动作重新认证；新凭据验证前保留旧凭据；不按同邮箱自动绑定 |
| 实例认证与邮件 | 固定公开Origin、RP、Google/SMTP配置、revision、真实测试邮件 | 管理员及最近认证；秘密只写不显；冲突保留本地草稿；变更目的地不能继承秘密 |
| 对话 | 模型/代理、文本、可见范围、发送/停止、重置/分支、分页 | 流和终态、工具轨迹、费用未知；重置保留历史，分支不改原记录，搜索说明仅已加载 |
| 运行与收件箱 | 运行过滤/详情、取消、投递回执 | 生成/发送/持久化分别真实，unknown保留，不自动重放 |
| 模型 | 已支持provider、真实模型ID/URL、密钥、token、单价、私网 | 向导、枚举来源和限制清楚；发现列表可取消，变更目标忽略旧响应；逐步校验并关联字段，Enter核对前只前进；保存与真实测试分开，最多8测试输出token |
| 机器人与渠道 | 当前Webhook、目标、token、批准/启用、正文发送 | 逐步校验URL和令牌，Enter核对前只前进；默认停用，无虚构无副作用测试；同key继续POST可能首次发送，只有receipt GET只读 |
| 插件 | 包、隔离实例、配置、启停/reload | 声明不等授权；安装/配置/实际进程调用不同；无可用包给教程入口 |
| 知识库 | UTF-8文本/Markdown导入、查看/检索/删除 | 512KiB客户端上限及后端约束；原文和引用位置；其他格式明确不支持 |
| 记忆 | 显式内容、source、enabled/archived/pinned | 可改/停用/归档/恢复，与删除不同；无隐式全量学习 |
| 计划任务 | once/interval/cron、模型/会话、可搜索IANA时区/常见频率与自定义、真实preview/手动运行 | 显示未来时间的计划时区、设备换算和暂停；修改配置/身份使旧预览失效，错误定位字段且保留草稿；preview无模型/资源写入/派发；沿用DST/skip，只有所有者改配置 |
| 代理 | 名称/系统提示、默认模型、max_steps、知识/记忆开关 | 共享会话仅列共享代理，运行冻结快照；用户可覆盖默认模型 |
| 成员与设置 | 角色、账户创建、预算、可见导出、敏感备份/审计 | 实例与工作区权限分开，预算使用整数微美元，审计不含私人正文 |
| 开发者教程 | 启动、四SDK、只读插件、协议/构建验证、文档/技能 | 嵌入步骤可读，权威链接准确；能力/缺口与真实接口一致 |
| 构建提示词 | 仓库基线、当前实例来源/已认证用户的本地草稿、保存/差异/恢复/导出 | 最多20版本、带时间；身份变化拒绝旧内存/迟到读写，旧全局键不自动认领或删毁；浏览器本地写入不等于仓库更新 |

日期/数值按字段类型转换，不能把token等普通数字交给日期格式化。资源ID不让用户猜已知选项，开放内容仍允许编辑。权限只影响显示，服务端始终重新判断。UI可跟随当前安装包，但不能把仅声明model能力的第三方包当作已通过核心provider集成。无相应HTTP能力时显示准确不可用状态并保留蓝图任务。

开发预览生产模式用核心同源服务web/dist。当前Vite跨端口代理曾因严格Origin校验拒绝mutation；运行教程应验证同源方案或明确正确代理Origin配置，不要求关闭服务端CSRF保护。

网络传输失败用当前语言说明连接检查、草稿保留及结果核对后手动继续，技术原文放次要详情；不自动补发，不把无法确认的结果说成确定未送达。恢复/迟到确认不能清空后来输入的新稿；401/403保持独立权限处理。RFB-001/002/003在反馈时为已观测而未修复；随后1.11本地修复及34项Web、11＋7项浏览器证据见根CURRENT_SCOPE.md/SOURCE_EVIDENCE.md。该来源证据不替代本轮重建、其他环境或1.13新增验收。保留Web验收20/21/22并追加CAPABILITY_WORKFLOWS.md。
