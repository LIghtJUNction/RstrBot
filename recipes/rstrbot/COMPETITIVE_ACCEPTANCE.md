# 端到端对比与上游问题改进合同

用户目标是比AstrBot、MaiBot（用户所说 MainBot）更好用并全面超越OpenClaw。本文件将愿景转为可验证工作，不预设对比结论。RstrBot、AstrBot 和 OpenClaw 已有部分本地正常路径证据；OpenClaw v2026.10.8 另完成 transcript 冲突与 HTTP 404 回退的局部复测。MaiBot v1.3.18 因其明确的条款阅读/同意门槛而未运行。12项完整共同任务尚未通过，不能声称总体领先。

## 来源和比较边界

AstrBot为AstrBotDevs/AstrBot，OpenClaw为openclaw/openclaw；用户于2026-10-29确认其所说 MainBot 是麦麦 MaiBot，对应官方仓库 Mai-with-u/MaiBot。身份确认只解除项目识别疑问，不代表运行过或胜出。

执行前记录每个产品的release/commit、包/二进制摘要、OS/CPU/RAM、数据库/缓存/浏览器、配置与插件版本、数据规模、网络/供应商模型/参数、成本前提和测试日期。各自使用独立数据根、账号和端口，保留正式配置，按公开文档从普通用户入口操作，不使用开发者内幕替代新手流程。不下载无关私有数据，不动现有服务或真实聊天平台。

同能力下尽量固定同一模型/上游延迟夹具、相同资料和故障脚本；真实模型质量与诊断流程分开，凭据、商业账号、平台或设备不足记blocked/not_executed。无法运行对方不计为对方失败，文档宣称不计为实测成功；RstrBot未实现能力记缺口，不用隐藏功能或缩小能力清单取得胜利。

## 判断“更好用/超越”

先检查功能、隔离、权限、数据正确性、取消、预算和未知副作用门槛，任何关键倒退不能被速度或界面分数抵消。任务成功后再记录实际步骤/手工编辑、求助/错误次数、完成及恢复时间、p50/p95/p99、RSS和请求/费用；统计须按PERFORMANCE保留硬件、负载、重复及失败样本，未测数字保持未知。

客观步骤/时间可以比较，Agent模拟不能提供人类满意度或总体体验比例。仅在冻结的能力与任务清单各关键维度均无未解释倒退、所有P0通过、指定优势有同条件证据时，才报告限定范围内领先；缺能力、blocked和not_executed须展示。当前不得报告“已全面超越”。

## OpenClaw issue转配方

有界检索优先本项目和共同任务相关的OpenClaw问题，逐条阅读正文、关键评论、状态与修复来源；保留查询日期及仓库版本。每条记录稳定OC编号、用户场景/障碍、证据类型、当前状态、是否本地复现、适用性/反例、最小行为变化、优先级、所属RB/组件合同与验收ID。

相同根因合并而不丢来源；过期/重复/拒绝/已修复分别记录，机器人源代码评审不是实机复现。Issue建议实现只是选项，不扩大本项目权限或强制复制上游结构。仅有线索先列待验证，已证明的共同失败或明确目标才进入配方；每次选定改进同步BUILD_PROMPT、组件合同、ACCEPTANCE与CHANGELOG，再重建、故障注入和下游验收。正文/日志保留在配方外，归档仅存精选要求、链接和自足验收。
