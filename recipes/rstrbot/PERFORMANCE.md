# 性能与容量验收计划

用户确认暂无数字预算。启动时间、空闲/峰值RSS、p50/p95/p99延迟、吞吐、网络、包体积和目标低性能设备均为未知。本次迁移未运行应用基准，不提供新的通过结果。来源中的128条分页、16MiB批次、1MiB RPC帧、8 worker槽位等属于行为/资源边界，不是性能达标指标。来源提到1vCPU/1GiB是待测候选环境，不是已实测目标设备。

| 工作负载 | 数据与操作 | 必须测量的量 |
| --- | --- | --- |
| 启动/恢复 | 空库、正常历史、runs/deliveries/schedules各10025记录，尾部含未完成事实 | 恢复完成到ready/可监听耗时，峰值RSS，扫描批次/数据库耗时，副作用重放次数必须0 |
| 对话 | 单用户、多用户/工作区，受控延迟的模型片段流及工具续轮 | 队列/模型/工具/持久化/渲染分段时延，吞吐、p50/p95/p99、RSS与事件积压 |
| 并发与背压 | 填满8worker槽后再排队；慢消费者、超大帧和撤权 | 拒绝/超时延迟，实际活跃进程与队列上界，资源最终回收 |
| 历史与分页 | 超过200资源、长会话，前翻消息并切换工作区/会话 | 首屏/续页耗时、渲染卡顿、读取锚点、缓存与内存增长 |
| 数据库/缓存 | SQLite/PG × Valkey关闭/开启/中断 | 事务/写排队耗时、错误率、公平性、RSS；权限与预算语义保持 |
| 前端/动效 | 320/390/768/1024/1440px，粒子暂停/离屏/减少动作 | 首次资源字节、加载/交互时延、动画帧与CPU、后台停止；设备与浏览器版本 |

每次记录CPU/架构、RAM、存储、OS/内核、数据库/缓存/浏览器版本、构建profile和摘要、数据集种子/规模、并发、上游延迟分布、冷/热缓存、预热、重复次数、统计方法和失败样本。先建立基线，再由实际负载选择数字门槛；不同硬件、debug/release、不同数据集不直接合并为提升倍数。外部服务质量、包gzip体积、容量恢复成功与端到端性能分开记录。
