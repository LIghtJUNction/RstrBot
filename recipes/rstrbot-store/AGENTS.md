# 配方工作约定

本目录保存重建说明。请在独立实现目录生成软件，保留本配方作为可审阅输入。不得把实现源码、二进制、安装脚本、数据根、密钥、可执行钩子或文件系统链接放进配方。

阅读 BUILD_PROMPT.md、ACCEPTANCE.md 和全部声明依赖。依赖别名仅在当前包作用域中有效。重建先满足可观察接口、权限和失败语义，不要求复制原内部结构。外部服务、未实现能力和未知性能指标必须明确记录。

验收记录包含实际命令、时间、平台、输入规模、产物摘要及 passed / failed / not_executed / blocked；不能把历史回执、模拟上游、打包成功或未运行的测试写成新实现已通过。
