# rstrbot-store 验收

以下是未来重建必须执行的验收方案。本次迁移未执行这些软件场景。每项使用独立临时数据与测试账号，记录平台和结果。

| 编号 | 输入与操作 | 预期结果 |
| --- | --- | --- |
| RSTRBOT-STORE-01 | SQLite/PG分别建立两用户两工作区及同名资源，尝试换wid/id、分页、检索、事件和导出 | 当前权限下无跨工作区/私有泄漏；结果语义一致 |
| RSTRBOT-STORE-02 | 实例管理员未加入工作区，及成员读取他人的共享会话 | 前者无工作区写权；后者可读但不可擅自改/发 |
| RSTRBOT-STORE-03 | 两个客户端持相同资源version并发修改/删除 | 仅一个成功；另一个冲突，内容不被静默覆盖 |
| RSTRBOT-STORE-04 | 并发初始化、移除最后所有者、未知角色输入 | 仅持有效初始化证明的一次事务成功；危险角色变化拒绝 |
| RSTRBOT-STORE-05 | 注销/改密/移出工作区后再读资源与排队操作 | 使用最新授权；已知费用/回执保留 |
| RSTRBOT-STORE-06 | 5分钟最近认证、过期挑战、重复使用邮箱/Passkey/Google意图 | 挑战单次消费且过期拒绝；最近认证不延长会话 |
| RSTRBOT-STORE-07 | 同时预留超过工作区预算，usage或价格缺失 | 并发限额一致；缺失费用未知，不伪造0 |
| RSTRBOT-STORE-08 | 他人修改共享计划、管理员删除共享计划、认领后所有者降权 | 按所有者配置权和管理删除权区分；失权不继续执行 |
| RSTRBOT-STORE-09 | 准备/发送中的投递与运行、计划各10025条历史，重启 | 扫描到末尾；按阶段恢复，listener在恢复完成后启动，无重发 |
| RSTRBOT-STORE-10 | 备份后导入空目标和非空目标 | 空目标进入暂停恢复；非空拒绝；无活跃会话复活 |
| RSTRBOT-STORE-11 | 仅备份数据库却未恢复secrets.key或外部插件状态 | 明确缺少必要恢复材料，不伪报完整灾备成功 |
| RSTRBOT-STORE-12 | Valkey关闭/可用/中断时执行同一权限与预算流程 | 持久业务一致，可报告degraded而不扩大权限 |
